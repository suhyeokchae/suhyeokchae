# 채수혁

**소프트웨어학과 학부생 | 웹 개발과 데이터 기반 서비스에 관심이 있습니다**

기본기를 충실히 익히고, 배운 내용을 실제로 동작하는 소프트웨어로 구현하는 과정을 중요하게 생각합니다.  
작은 프로젝트를 통해 문제를 정의하고 해결하는 경험을 쌓고 있습니다.

---

## 소개

- 소프트웨어학과에서 프로그래밍과 컴퓨터 과학의 기초를 공부하고 있습니다.
- 웹 서비스의 구조와 사용자 경험에 관심이 있습니다.
- 기능을 구현하는 것뿐 아니라 코드의 가독성과 유지보수성도 함께 고민합니다.
- 학습한 내용과 프로젝트 과정을 GitHub에 기록하고 있습니다.

## 관심 분야

- 웹 프런트엔드 개발
- 백엔드 시스템의 기본 구조
- 데이터베이스 설계와 활용
- 사용자 중심의 소프트웨어 설계

## 기술

학습 및 프로젝트에서 사용해 본 기술을 중심으로 정리했습니다.

| 분야 | 기술 |
|---|---|
| 프로그래밍 언어 | Python, Java, JavaScript |
| 웹 기초 | HTML, CSS |
| 데이터베이스 | MySQL 기초 |
| 개발 도구 | Git, GitHub, Visual Studio Code |

## 프로젝트

### 캠퍼스 일정 관리 웹 페이지

수업 일정과 과제 마감일을 한곳에서 확인할 수 있도록 만든 개인 학습 프로젝트입니다.

- **주요 기능:** 일정 등록, 일정 목록 확인, 완료 항목 표시
- **사용 기술:** HTML, CSS, JavaScript
- **진행 과정:** 화면 구성과 기본 기능을 구현하고 사용성을 개선하고 있습니다.
- **배운 점:** 입력값을 다루는 방법과 화면 상태를 관리하는 기초를 익혔습니다.

### 도서 대여 관리 프로그램

도서 정보와 대여 상태를 관리하기 위해 만든 콘솔 기반 프로그램입니다.

- **주요 기능:** 도서 등록, 검색, 대여 및 반납 상태 관리
- **사용 기술:** Java
- **진행 과정:** 객체를 역할별로 나누고 기능을 단계적으로 구현했습니다.
- **배운 점:** 클래스와 메서드의 역할, 자료를 구조적으로 관리하는 방법을 연습했습니다.

## 학습 기록

- 자료구조와 알고리즘의 기본 개념을 공부하고 있습니다.
- Git의 기본 명령어와 협업을 위한 브랜치 사용법을 익히고 있습니다.
- 웹 페이지의 구조와 접근성을 고려한 HTML 작성 방법을 학습하고 있습니다.
- 프로젝트에서 발견한 문제와 해결 과정을 문서로 남기고 있습니다.

## 앞으로의 목표

1. 자료구조와 알고리즘의 기본기를 꾸준히 다지기
2. 프런트엔드와 백엔드가 연결되는 웹 서비스를 완성하기
3. 프로젝트마다 설계 이유와 구현 과정을 명확하게 기록하기
4. 다른 개발자의 코드를 읽고 협업하는 경험 쌓기
